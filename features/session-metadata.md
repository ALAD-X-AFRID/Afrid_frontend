# Session Metadata

## What It Is About
Unique identifier for each telemetry session and an index of total events recorded. The `is_human` flag labels the data as human (1) or bot (0) for supervised learning.

## How It Is Calculated
- **session_id**: Generated as `"BANKSIM-" + Date.now()` at session start
- **event_index**: Count of all telemetry events pushed to the in-memory event log
- **is_human**: Hardcoded to `1` for human participants

## SI Unit
- session_id: string (dimensionless identifier)
- event_index: count (integer)
- is_human: boolean (0 or 1)

## Physical Device Used
No sensor required. Generated by the application runtime.

## Export Columns
| Column | Type | Description |
|---|---|---|
| session_id | string | Unique session identifier |
| event_index | integer | Total number of telemetry events |
| is_human | integer | 1 = human, 0 = bot |

## Bot Detection Rationale
Bots produce significantly more or fewer events than humans for the same task. An abnormally high or low event_index for a completed session is a bot signal. The session_id enables cross-session comparison and replay analysis.
